# Northstar Support Chatbot MVP

A browser-based decision-tree chatbot that deflects repetitive support tickets for **Northstar Retail Co.**  
No backend required — runs entirely in the browser.

**Sprint Deadline:** Saturday, 11:59 PM  
**Team:** PLP Group 41

---

## What It Does

Handles **2 of 3** support ticket types without a human agent:

| Ticket Type | Example Questions |
|-------------|-------------------|
| **Order Status** | "Where is my order?" / "Has it shipped?" |
| **Returns & Refunds** | "How do I return this?" / "When will I get my refund?" |
